为什么推荐同时配置一个苹果「快捷指令」？

出门用 5G 流量或电脑关机时，电脑上的本地服务连不上；在 iPhone「快捷指令」里建一个 4 步指令并添加到桌面，就能随时随地直连 SpicyAPI 生图并存进相册。

1
动作 1：要求输入（Ask for Input）

提示设为「输入生图描述」，输入类型选「文本」。

2
动作 2：获取 URL 内容（Get Contents of URL）

URL 填：https://api.spicyapi.ai/api/v1/jobs/createTask?wait=60
方法选 POST，Headers 添加：
Authorization = Bearer 你的sk-spicy-Key
Content-Type = application/json

请求体选 File / JSON（或直接选「请求体 -> JSON」），可用下面模板：

{
  "model": "bytedance/seedream-5.5/text-to-image",
  "input": {
    "prompt": "[把这里替换为第1步的 Provided Input]",
    "aspect_ratio": "3:4",
    "resolution": "2k",
    "output_format": "png"
  }
}
3
动作 3：获取词典值（Get Dictionary Value）

依次取 data.output.assets → 获取列表第一项 → 取 url（在快捷指令里可直接写点号路径 data.output.assets.1.url）。

4
动作 4：获取 URL 内容 → 保存到相册（Save to Photo Album）

把上一步拿到的图片链接下载为图片并保存到「最近项目」，最后可在指令顶部菜单点「添加到主屏幕」。
